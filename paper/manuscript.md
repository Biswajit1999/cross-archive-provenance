# Cross-Archive Provenance Audit: Methods and Results (v0.2.0)

**Author**: Biswajit Jana

## Abstract

We audit how reliably real confirmed-exoplanet host stars from the NASA
Exoplanet Archive can be cross-identified and positionally cross-matched
against SIMBAD, using live queries to both public services, with a
retry-and-distinguish mechanism that separates a query that fails to
complete (network error, timeout) from a query that completes and
genuinely finds no match. Of 293 real host stars audited, 91.5% resolve
in SIMBAD by exact name (0 names had a query that could not be completed
at all after retries); of those, 95.1% agree in position within 5 arcsec
(median separation 0.28 arcsec, max 20.1 arcsec). Of the unresolved
names, 84% are microlensing-survey lens designations (KMTNet, OGLE, or
MOA), consistent with those lens stars lacking a standalone SIMBAD entry;
the four largest position discrepancies are all nearby, high-proper-motion
M dwarfs, consistent with an epoch-difference explanation. This project
measures and flags cross-archive (dis)agreement; it does not adjudicate
which archive is correct for any specific object.

## 1. Introduction

Downstream astronomical analyses routinely combine data from multiple
archives under the (often implicit) assumption that a shared object name
or position reliably identifies "the same object." This project makes
that assumption directly testable and quantified for a real, well-defined
sample (confirmed exoplanet host stars), using two of the most heavily
used public archives.

## 4. Results

All numbers below are read from `results/default/`, generated by
`provenance run --n 300` (`docs/REPRODUCIBILITY.md`).

| Quantity | Value |
|---|---|
| Host stars queried | 293 |
| Query could not be completed after retries | 0 |
| Resolved in SIMBAD | 268 (91.5%) |
| Genuinely not found in SIMBAD | 25 (8.5%) |
| Resolved objects within 5 arcsec of the archive position | 255 (95.1%) |
| Median separation (resolved) | 0.28 arcsec |
| Max separation (resolved) | 20.1 arcsec |

Of the 25 unresolved names, 21 (84%) are microlensing-survey lens
designations (11 `KMT-*-BLG-*L` KMTNet, 9 `OGLE-*-BLG-*L`, 1
`MOA-*-BLG-*L`); the remaining 4 (`Lupus-TR-3`, `Qatar-5`, `Qatar-8`,
`TIC 320419023`) are not microlensing objects and are not explained by
that pattern (`docs/LIMITATIONS.md`). The four largest position
discrepancies, sorted by separation, are HD 285968 (20.1"), GJ 876
(18.1"), GJ 674 (16.3"), and GJ 328 (16.2") -- all nearby M dwarfs.

## 5. What this result does and does not show

This demonstrates that cross-archive identification is highly but not
perfectly reliable for a real, well-studied object class, and that the
specific failure modes (unconfirmed microlensing lenses; proper-motion-
driven position drift for nearby stars) have physically sensible
explanations rather than being unexplained anomalies. It does **not**
independently confirm the proper-motion explanation (no Gaia
proper-motion cross-check performed), does not extend to a third archive,
and does not generalize beyond the exoplanet-host-star sample tested.
