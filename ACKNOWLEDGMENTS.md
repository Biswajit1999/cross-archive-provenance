## Data and context

- Host-star names and positions: NASA Exoplanet Archive, table
  `pscomppars` (Planetary Systems Composite Parameters), queried live via
  TAP, no authentication required.
- Independent identifier resolution and positions: SIMBAD astronomical
  database (CDS, Strasbourg), queried live via its public TAP service, no
  authentication required.
- This project is an independent audit and is not an official NASA
  Exoplanet Archive, IPAC, CDS, or SIMBAD product, and is not affiliated
  with or endorsed by those organizations.
